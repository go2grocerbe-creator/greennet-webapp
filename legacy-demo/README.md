# Legacy Demo

This is the original client-facing demo (`index.html`, `styles.css`, `script.js`) delivered before production discovery and the Next.js/Supabase migration.

- It is preserved here for **visual and interaction reference only**.
- It is **not** the production architecture. The production application lives at the repository root (`src/`, `app/`) and is described in `docs/architecture.md`.
- Files here are unmodified from their pre-migration state — see `docs/current-demo-audit.md` for the full audit and `docs/content-register.md` for what is safe to port versus what must be replaced.
- Any stock photography, flyer imagery, or unverified project photos referenced by or accompanying this demo **must not** be reused as real GreenNet project evidence. See `docs/content-register.md` and the `media.rights_confirmed` gate in `docs/data-model.md`.

The full, permanently retrievable state of this demo (plus the completed planning docs) is also preserved on the `legacy/static-demo` branch.
